# de_tarot

**A hand-drawn Counter-Strike tarot.** Walk down the tunnel, take a seat with The Seer, and let three Major Arcana call your next CS2 match.

- 🃏 **The reading**: shuffle, deal, and flip three cards: pistol round, mid round, clutch. Upright or reversed, they add up to a Premier forecast and a CS Rating swing.
- 🖼️ **The gallery**: all 22 Major Arcana, each one drawn by hand. Pick one up and inspect it like a skin (press `F`).
- 🐔 Yes, you can poke the chicken.

The deck is a work in progress. New cards land as they get drawn.

## Run it

```bash
npm install
npm run dev
```

Built with [three.js](https://threejs.org), [GSAP](https://gsap.com) and Vite. Works with keyboard and screen readers, and respects reduced-motion settings.
